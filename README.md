# V!PER MD OFC – WhatsApp Bot + Web Panel

## Deploy to Heroku
1. Fork this repository.
2. Create a new Heroku app.
3. Add environment variables (see `.env.example`).
4. Deploy the branch.
5. Open the app URL to pair your WhatsApp number.

## Local Setup
1. `git clone https://github.com/darksasa-eng1/viper-md.git`
2. `npm install`
3. Rename `.env.example` to `.env` and fill in your MongoDB URI and Groq API key.
4. `npm start`
5. Visit `http://localhost:3000` to connect the bot.

## Commands
Use `.menu` in chat to see all 100+ commands.
